# Examination Rules

1. Do not rename the required route files.
2. Do not remove TODO EXAM comments until the requirement has been completed.
3. The project must run successfully using npx expo start.
4. Students must use Expo Router.
5. Students must use fetch() and async/await for API requests.
6. Students must demonstrate useState and useEffect.
7. Student records must come from the provided API.
8. Students must implement a dynamic [id] route.
9. Authentication tokens must not be hardcoded.
10. Plain-text passwords must not be stored.
